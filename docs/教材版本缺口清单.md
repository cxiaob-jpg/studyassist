|---|---|---|---|

| 湘教版 | 54 | 已收录 | xjb |
| 鲁教版 | 10 | 已收录（6~7 年级，五四制） | ljb |
| 中图版 | 5 | 已收录 | ztb |
| 晋教版 | 4 | **★缺失** | jjb |
| 商务版 | 1 | **★缺失** | swb |

缺口原因（都不是「不想做」）：
- **晋教版**：dzkbw 只有七上（2024 新版主题式目录：主题一 探寻人类的太空家园 /
  主题二 模拟地球运动 / 主题三 探索地球海陆面貌 / 主题四 寻找地球上的居住地），
  七下、八上、八下目录页返回空。仅 4 城。
- **商务版**：只有七上 / 七下（世界地理），dzkbw 无八上 / 八下，缺「中国地理」半区，
  生成残缺 TOC 会让中国地理知识点挤爆个别章，脚本已主动跳过。仅 1 城。

另注：中图版把「中国地理」放七年级、「世界地理」放八年级，与人教相反；鲁教版为
五四制，地理从六年级开课。因此 `build_geography_toc.py` 不按年级对齐，而是给每册
标地缘（世界/中国）、每章标层级（大洲/地区/国家），强制同区同层匹配。

## 八、历史（history）

已收录 1 版：`tongbian` 统编版（7~9 年级，6 卷 / 133 知识点 / 497 题）。

地区实际：无 `o.lishi` 字段，全国统编——**无版本缺口**。

TOC 已在 2026-11-20 补齐（`data/toc/history/tongbian/`，6 卷）。历史是唯一
「知识点本来就按教材单元组织」的学科——`data/knowledge/history/gX*.json` 的
units/topics/questions 单元 id 与 catalog 完全一致（u1..uN），所以生成脚本
`build_history_toc.py` 只做恒等重挂：用 catalog 的单元名（带「·」分隔符）
覆盖，让知识点页/报告的章节名与设置页显示的版本名统一。

| 北师大版 | 33 | 已收录 | bsd |

**无缺口**。两处数据说明：
- `cities.json` 里冀少版被记成了 `jsb`（出版社代码），不是抓取残留。自动选版
  的映射表同时认 `"冀少版"` 和 `"jsb"` 两个键。
- 生物各版本对同一内容的分册差异很大：人教版八上讲人体（二）、苏教版七下就
  讲植物、北师大版七上讲植物、苏科版七上讲生物与环境。因此 `build_biology_toc.py`
  同样不做年级对齐，走整学段章节池 + 内容匹配。

单元打标）；其余六家用「章」，因为这些版本一个单元动辄含 5~6 章（北师大七下
只有一个单元）、用单元会把十几个知识点堆成一坨。

## 十、补版优先级建议

已完成：物理（12 版）→ 化学（6 版）→ 地理（4 版，剩晋教/商务）→ 数学（8 版，剩初中 4 家）
→ 生物（7 版）→ 历史（统编 1 版）。

剩余按覆盖城市数排序：

1. **英语**：外研版 → 仁爱版 → 北师大版 → 冀教版 → 鲁教版（覆盖 197 城，缺口最大）
3. **数学**：湘教版 → 沪科版 → 苏科版 → 浙教版（初中段，覆盖 64 城）
4. **地理**：晋教版（4 城，需换源站补目录）、商务版（1 城，缺八上/八下）
5. **历史**：已完成（统编单版本，TOC 恒等重挂）

补版统一按物理方法：catalog 注册版本 → dzkbw 抓真实章目录 →
通用知识点/题目池按章重挂 → 生成 `data/toc/<学科>/<ed>/gX{u,l}.json` →
接 `cities.json` 出版社→edition id 的自动选版映射（`ui/mainview.lua` 的
`OTHER_EDITION_ID` / `OTHER_MIN_GRADE`）。
